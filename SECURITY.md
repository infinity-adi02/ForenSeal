# Security policy

ForenSeal is a local demonstration and has not been reviewed for production use. Do not use it to store real investigative evidence or other sensitive data without an independent security review and appropriate operational controls.

Do not post evidence files, personal data, credentials, admin codes, or exploit details in public GitHub issues or pull requests. If GitHub private vulnerability reporting is enabled for this repository, use it to report suspected vulnerabilities. Otherwise, contact the maintainer privately before public disclosure.
